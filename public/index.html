FAQ

Frequently asked questions

Do I have to define a template for each document layout?

No. You pass a list of field names with the request. Fieldcast reads the document and returns those fields. A supplier changing their invoice layout requires no change on your side.

What file types are supported?

PDF and plain text today. PDFs are converted to text server-side before extraction. Scanned image-only documents need OCR, which is not yet available.

What happens if a field is missing from the document?

It is returned as null. Fieldcast does not invent values to fill a schema, because a plausible wrong total is more expensive than a missing one.

How accurate is it?

On the reference ten-field invoice test, all ten fields were extracted correctly, with dates normalised to ISO-8601 and monetary values returned as numbers. Measure accuracy on your own documents — that is what the free tier is for.

Can an AI agent use Fieldcast without an account?

Yes. The x402 endpoint requires no API key. The agent receives payment terms as an HTTP 402 response, settles in USDC, and receives the extraction in the same request flow. It runs on Base mainnet: $0.01 per document in USDC.

Is my document stored?

Document contents are not persisted. Only a usage counter — API key, month, call count, character count — is recorded for billing.
